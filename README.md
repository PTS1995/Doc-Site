# Ιστοσελίδα — Βασίλειος Λυγίζος, Μαιευτήρας – Γυναικολόγος

Στατική ιστοσελίδα (HTML/CSS), χωρίς κόστος φιλοξενίας μέσω GitHub Pages.
Τα κείμενα προέρχονται από το έγγραφο «Lygizos_Keimena_Istoselidas.docx».

## Σελίδες (μενού)

| Μενού | Αρχείο |
|---|---|
| Αρχική | `index.html` |
| Ο ιατρός | `o-iatros.html` |
| Γυναικολογία & Μαιευτική | `gynaikologia-maieftiki.html` |
| Γυναικολογική ογκολογία | `gynaikologiki-ogkologia.html` |
| Πρώτη επίσκεψη | `proti-episkepsi.html` |
| Επιστημονικό έργο | `epistimoniko-ergo.html` |
| Επικοινωνία | `epikoinonia.html` |

Άλλα αρχεία: `styles.css` (εμφάνιση), `main.js` (μενού κινητού),
`favicon.svg` (εικονίδιο καρτέλας), `404.html` (σελίδα «δεν βρέθηκε»),
`images/` (φωτογραφίες).

## Πριν από τη δημοσίευση

1. **Τηλέφωνο ιατρείου** — στο `epikoinonia.html`: αντικαταστήστε το
   «Προς συμπλήρωση» και το `tel:` στο κουμπί «Καλέστε το ιατρείο».
2. **Ωράριο και email** — υπάρχει έτοιμο (σε σχόλιο) σημείο στο
   `epikoinonia.html`. Συμπληρώνονται μόνο με στοιχεία που επιβεβαιώνει ο ιατρός.
3. **Φωτογραφία** — ανεβάστε μια κάθετη φωτογραφία (αναλογία 4:5) με όνομα
   `images/vasileios-lygizos.jpg`. Εμφανίζεται αυτόματα στην Αρχική και στο
   «Ο ιατρός». Μέχρι τότε φαίνεται το μονόγραμμα «ΒΛ».

## Βίντεο φόντου στην Αρχική (προαιρετικό)

Ανεβάστε ένα σύντομο βίντεο χωρίς ήχο (10–20 δευτ., MP4, ιδανικά κάτω από 5 MB)
ως `images/hero.mp4`. Θα παίζει αυτόματα, απαλά, πίσω από το όνομα του ιατρού.
Χωρίς βίντεο εμφανίζεται το κινούμενο χρωματικό φόντο.

## Κίνηση

Τα εφέ (εμφάνιση στοιχείων με την κύλιση, κινούμενο φόντο, ταινία θεμάτων,
απόφθεγμα που «ανάβει») βρίσκονται στα `styles.css` και `main.js`. Για όσους
έχουν ενεργοποιήσει «λιγότερη κίνηση» στη συσκευή τους, απενεργοποιούνται αυτόματα.

## Αλλαγή χρωμάτων

Στην κορυφή του `styles.css`, η τιμή `--brand` (#1F585C) είναι το βασικό χρώμα.

## Δημοσίευση δωρεάν (GitHub Pages)

1. GitHub → repository → **Settings** → **Pages**
2. «Source»: **Deploy from a branch** → branch `main`, φάκελος `/ (root)` → **Save**
3. Σε 1–2 λεπτά: `https://<username>.github.io/Doc-Site/`

## Δικό σας domain (~10–15 €/χρόνο)

Αγορά `.gr` από ελληνικό καταχωρητή (π.χ. papaki.com), μετά
Settings → Pages → «Custom domain», και CNAME record προς `<username>.github.io`.
