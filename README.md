1. **Ωράριο** — υπάρχει έτοιμο (σε σχόλιο) σημείο στο `epikoinonia.html`.
   Συμπληρώνεται μόνο με στοιχεία που επιβεβαιώνει ο ιατρός.
2. **Φωτογραφία** — ανεβάστε μια κάθετη φωτογραφία (αναλογία 4:5) με όνομα
   `images/vasileios-lygizos.jpg`. Εμφανίζεται αυτόματα στην Αρχική και στο
   «Ο ιατρός». Μέχρι τότε φαίνεται το λογότυπο.

## Δημοσίευση δωρεάν (GitHub Pages)

1. GitHub → repository → **Settings** → **Pages**
2. «Source»: **Deploy from a branch** → branch `main`, φάκελος `/ (root)` → **Save**
3. Σε 1–2 λεπτά: `https://<username>.github.io/Doc-Site/`

## Δικό σας domain (~10–15 €/χρόνο)

Αγορά `.gr` από ελληνικό καταχωρητή (π.χ. papaki.com), μετά
Settings → Pages → «Custom domain», και CNAME record προς `<username>.github.io`.
