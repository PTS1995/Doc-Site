# Doc-Site — Ιστοσελίδα Ιατρείου

Απλή, γρήγορη και **δωρεάν** ιστοσελίδα ιατρείου (στυλ inutero.gr).
Φτιαγμένη με σκέτο HTML/CSS — δεν χρειάζεται κανένα πρόγραμμα ή συνδρομή.

## Τα αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Όλο το περιεχόμενο της σελίδας (κείμενα, ενότητες) |
| `styles.css` | Η εμφάνιση (χρώματα, γραμματοσειρές, διάταξη) |

## Πώς να αλλάξετε το περιεχόμενο

1. Ανοίξτε το `index.html`
2. Αντικαταστήστε τα placeholder κείμενα:
   - `Δρ. Όνομα Επώνυμο` → το όνομα του ιατρού
   - `Υπηρεσία 1/2/3/4` → τις πραγματικές υπηρεσίες
   - Τηλέφωνο, διεύθυνση, email, ωράριο στην ενότητα «Επικοινωνία»
3. Για φωτογραφίες: ανεβάστε μια εικόνα (π.χ. `photo.jpg`) στον φάκελο και
   αντικαταστήστε το πλαίσιο «Φωτογραφία» με `<img src="photo.jpg" alt="...">`
4. Για τον χάρτη: Google Maps → «Κοινοποίηση» → «Ενσωμάτωση χάρτη» →
   επικολλήστε το `<iframe>` στη θέση του «Χάρτης Google Maps»

Για να αλλάξετε το βασικό χρώμα, ανοίξτε το `styles.css` και αλλάξτε
το `--primary` στην κορυφή του αρχείου.

## Πώς να δημοσιεύσετε ΔΩΡΕΑΝ (GitHub Pages)

1. Πηγαίνετε στο repository στο GitHub → **Settings** → **Pages**
2. Στο «Source» επιλέξτε **Deploy from a branch**
3. Επιλέξτε το branch `main` και φάκελο `/ (root)` → **Save**
4. Σε 1–2 λεπτά η σελίδα θα είναι ζωντανή στο:
   `https://<username>.github.io/Doc-Site/`

## Δικό σας domain (προαιρετικό, ~10–15€/χρόνο)

1. Αγοράστε ένα domain (π.χ. από papaki.com ή pointer.gr για `.gr`)
2. Στο GitHub: Settings → Pages → «Custom domain» → γράψτε το domain
3. Στον πάροχο του domain προσθέστε ένα CNAME record που δείχνει στο
   `<username>.github.io`
